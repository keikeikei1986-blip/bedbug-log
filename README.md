# BEDBUG LOG
トコジラミ対策・発見記録。HTML / CSS / JavaScriptだけで動作する静的Webアプリです。ビルド・バックエンド・ログイン・外部ライブラリは不要です。

## 使い方
`index.html` をブラウザで開いて利用できます。安定した保存にはGitHub PagesなどHTTP/HTTPSでの利用を推奨します（ファイル直接表示でのlocalStorageの扱いはブラウザによって異なります）。

- 発見・対策：ダッシュボードのボタンから登録。編集・削除はタイムラインで行います。
- 対策の部屋：和室・リビングなどを複数選択できます。候補にない部屋は自由入力でき、複数の場合は「、」で区切ります。以前の1部屋の記録もそのまま編集できます。
- 状況：ダッシュボードまたは経過観察のステータスを手動で変更します。
- 業者：会社名だけでも追加し、見積・施工・保証などを追記できます。
- 画面下の「バックアップ・復元」：ファイルに書き出し、別ブラウザで復元できます。復元はIDで統合し、同じIDはバックアップの内容に更新します。ステータスも復元します。

## GitHub Pagesへの公開
1. このフォルダの `index.html`、`style.css`、`app.js`、`.nojekyll` をリポジトリのルートへアップロードします（既存リポジトリでは独立したサブフォルダでも可）。
2. GitHubのリポジトリ設定で Pages の公開元ブランチとフォルダを選択します。
3. 発行されたURLを開きます。サブフォルダに置いた場合はURL末尾にそのフォルダ名を付けます。

## 保存と集計
- localStorageキー：`bedbug-log-v1`。同じブラウザ・同じオリジンに保存されます。サーバーへの送信・自動同期はありません。
- ブラウザデータ削除や端末故障に備えて、定期的にJSONを書き出してください。公開先を変える場合も移行前に書き出してください。
- 最終発見からの日数は、端末の現在日付と最後の発見日の暦日差です。記録がない場合は「—日」と表示します。
- グラフの期間は今日を含む7・14・30日間。未記録の日も0匹として表示します。未確認と発見なしを区別するチェック機能はありません。
- 発見の状態にかかわらず全匹数を集計します。写真は保存容量を優先して省略しています。
- 薬剤の使用日時は対策記録の日付・時刻です。異なる時刻の使用は別記録にしてください。
- 対応完了を自動判定しません。薬剤の安全性・医療上の判断もしません。

## 検証
JavaScript構文チェック、およびモックDOMによるロジックテストで、追加・編集・削除、localStorage書き込み、集計と経過日数、対策の複数選択、業者金額、30日グラフ、不正な日付・JSON構造の拒否、文字列のHTMLエスケープ、ステータス変更、保存JSONの再読込を確認しました。
この環境にはテスト用ブラウザがなく、実ブラウザのクリック操作・表示・ファイル入出力の一連のテストは未実施です。レスポンシブCSSは実装済みです。
